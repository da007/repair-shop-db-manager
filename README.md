# Repair Shop App 🛠️

Настольное приложение на **Python (Flet)** и **MySQL** для автоматизации работы мастерской по ремонту техники. 

## 🌟 Возможности
- **Ролевая модель:** Администратор, Оператор, Мастер, Кладовщик (с разным уровнем доступа к таблицам и роутам).
- **Управление сущностями:** Клиенты, устройства, заказы, запчасти, услуги и сотрудники.
- **Умный поиск:** Поддержка нечеткого поиска (алгоритм Левенштейна) по всем данным.
- **Безопасность:** Шифрование локального файла конфигурации и хеширование паролей пользователей (bcrypt).
- **Кастомизация:** Поддержка светлой/темной темы и акцентных цветов.
- **Адаптивность:** Интерфейс подстраивается под Desktop и Mobile.

## 🚀 Стек технологий
- **GUI:** Flet (Flutter под капотом)
- **База данных:** MySQL (`mysql-connector-python`)
- **Безопасность:** `cryptography`, `bcrypt`
- **Алгоритмы:** `python-Levenshtein`

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/da007/repair-shop-app.git
   cd repair-shop-app
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Разверните базу данных:
   - Создайте БД в MySQL и импортируйте дамп из папки `sql/Dump20250228.sql`.
4. Настройте переменные окружения:
   - Скопируйте `.env.example` в `.env` и впишите свои данные для БД и ключ шифрования.
5. Запустите приложение:
   ```bash
   flet run src
   ```
